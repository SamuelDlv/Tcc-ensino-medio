# Folhas de estilo

Os CSS desta pasta formam o design system do BetterOrganized. `base.css` contém tokens, navegação e controles compartilhados. `painel.css` define a sala de computadores, baias e ocorrências. Os demais arquivos atendem login, formulários, detalhes e relatórios.

Ao alterar um componente compartilhado, teste os perfis Professor e Suporte em desktop e celular.
