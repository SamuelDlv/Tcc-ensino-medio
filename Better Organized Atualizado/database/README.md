# Banco de dados

`schema.sql` é o instalador único do BetterOrganized. Ele cria o banco `betterorganized`, todas as tabelas, usuários de demonstração, quatro laboratórios e vinte máquinas de exemplo no Laboratório 1.

Execute a partir da raiz com `mysql -u root -p < database/schema.sql`. Em outro ambiente, substitua o usuário pelo usuário dedicado configurado para a aplicação.
