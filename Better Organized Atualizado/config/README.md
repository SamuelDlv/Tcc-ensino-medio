# Configuração

Esta pasta contém a conexão com o banco, as regras compartilhadas e o gerador interno de PDF. `database.php` lê as credenciais pelas variáveis `BETTERORGANIZED_DB_*`; não coloque senhas reais neste diretório. `helpers.php` concentra consultas e regras reutilizadas pelas telas. `SimplePdf.php` gera os relatórios em PDF sem dependências externas.

Consulte o README da raiz para a instalação completa e as recomendações de segurança.
